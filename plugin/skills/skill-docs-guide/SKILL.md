# Better-skills-manager

當使用者想要以管理一般文件的方式檢視、編輯、分類、檢查更新或分析 Skills 使用頻率與搭配關係時：

1. 直接執行 `open_skill_docs` 工具（可不帶參數，也可傳入 `tab: "finder" | "analytics" | "graph"`）在右側邊欄開啟 **Better-skills-manager** 面板。
2. 若使用者僅在對話中詢問摘要清單，可執行 `list_managed_skills` 取得受管理 Skills 的健康狀態、近 30 天使用次數與範圍分佈。
