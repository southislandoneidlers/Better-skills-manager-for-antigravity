# Skill 文件庫（Skill Docs）

讓管理 AI Skills 跟管理一般文件一樣簡單的 Antigravity 側邊欄外掛。

- **單一文件化與內嵌附件**：同畫面讀寫 `SKILL.md` 與 `scripts/`、`references/` 附件。
- **即時健檢與斷連一鍵修復**：偵測 Frontmatter 缺漏與不存在的相對連結並一鍵建立檔案。
- **Finder 多層分類 ＋ 不刪檔啟停**：自由建資料夾分類並自動同步 `skills.json`；停用自動收進 `_disabled/`。
- **發布／安裝時間 ＋ 更新檢查**：追蹤 Git 遠端與本機來源變更並支援一鍵備份更新。
- **365 天使用時間軸 ＋ 多技能協作關聯圖**：真實掃描對話紀錄與面板附加次數，分析引用、共現與重疊提示。
