# Better-skills-manager

讓管理 AI Skills 跟在 Finder 管理一般文件一樣簡單的 Antigravity 側邊欄外掛（支援繁體中文與英文介面）。

- **單一文件化與內嵌附件**：同畫面讀寫 `SKILL.md` 與 `scripts/`、`references/` 附件。
- **即時格式檢查與斷連修復**：偵測 Frontmatter 缺漏與不存在的相對連結並一鍵建立檔案。
- **Finder 多層分類與停用封存**：自由建資料夾分類並自動同步 `skills.json`；停用自動收進 `_disabled/`。
- **發布／安裝時間與更新檢查**：追蹤 Git 遠端與本機來源變更並支援一鍵備份更新。
- **365 天使用時間軸與多技能關聯圖**：掃描對話紀錄與面板附加次數，分析引用、搭配次數與重疊提示。
